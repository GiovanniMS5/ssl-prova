O comando openssl genrsa -out aluno.key 2048 é utilizado para gerar uma chave privada RSA, que é a base para criar conexões seguras e certificados digitais; detalhadamente, o termo genrsa indica ao OpenSSL para usar o algoritmo RSA, o parâmetro -out aluno.key define que o resultado (a chave gerada) deve ser salvo em um arquivo chamado "aluno.key" em vez de apenas ser exibido na tela, e o número 2048 especifica o tamanho da chave em bits, sendo este o padrão atual de mercado por oferecer um excelente equilíbrio entre segurança robusta contra ataques de força bruta e desempenho computacional, resultando em um arquivo essencial que deve ser mantido em total sigilo, pois ele permite descriptografar informações enviadas para o seu servidor.
Foi utilizado o comando ls -l aluno.key para poder visualizar o arquivo foi criado corretamente na pasta onde o terminal está.
