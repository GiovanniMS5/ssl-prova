O comando scp aluno.crt usuario@IP_DESTINO:/etc/ssl/certificates/ é utilizado para realizar a cópia segura do certificado recém-criado no computador para um servidor remoto através da rede, detalhadamente, o scp (Secure Copy) utiliza o protocolo SSH para criptografar a transferência, onde o primeiro argumento identifica o arquivo de origem (aluno.crt) e a segunda parte define o destino, composto pelo nome do usuário, o endereço IP da máquina de destino e o caminho exato da pasta onde o arquivo deve ser guardado, sendo este um passo fundamental para instalar o certificado no local correto onde o servidor web (como Apache ou Nginx) poderá encontrá-lo para proteger as conexões dos usuários. Para atender a estrutura desse projeto, o comando foi modificado para scp aluno.crt user@192.168.0.20:/etc/ssl/certificates/, onde esse usuário está em outra vm, foi criado o diretório /etc/ssl/certificates/ nessa nova vm e concedido para o user acesso a essa pasta, podendo assim dar continuidade sem problemas.
